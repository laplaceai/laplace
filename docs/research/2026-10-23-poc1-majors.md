# PoC 1: blinded Majors backtest

2026-10-23 · run `poc1` · code in `research/` · reproduce with
`uv run laplace-research majors run --run-id poc1 --days 30`

## Setup
- **Cards:** BTC, ETH and SOL, one every 6 hours for 30 days (348 cards; 343 scored by every agent). Each card has
  relative features only (returns, realized volatility, 7-day range position, volume ratio, the last 24 hourly
  returns). No ticker, price level or date.
- **Questions:** the 24-hour move in five bins (<−3%, −3…−1, ±1, 1…3, >3%), and whether the price moves more than
  2% within 4 hours (it did on 6.7% of cards).
- **Agents (15):** Clef-flash and Clef × six directives (none, plain, volatility, momentum, reversion, fat tails);
  DeepSeek V4.1 Flash with low reasoning × two directives; DeepSeek with no reasoning × one.
- **Reference:** a zero-mean Laplace distribution of log returns scaled by the last week's realized volatility.
  Skill = 1 − loss / reference loss (log score). Intervals: 95% bootstrap over whole days.
- **Cost:** 3.2M input tokens, about $0.50 in total.

## Results
| | 24 h skill vs Laplace-vol | 95% CI |
|---|---:|---|
| best raw agent (DeepSeek, volatility directive) | −0.029 | −0.073…+0.006 |
| best Clef agent (Clef, reversion) | −0.054 | −0.123…+0.017 |
| all agents pooled (equal weights) | −0.135 | −0.231…−0.044 |
| Hedge pool of agents + reference (2nd half) | −0.000 | |
| best shrunk agent (Clef, reversion; weight 0.45 fitted on the 1st half), 2nd half | +0.007 | |
| uniform | −0.204 | −0.332…−0.096 |

1. **No agent beats a one-line volatility model on Majors direction.** That was expected (liquid majors over 24 hours
   are close to efficient) and is why the blueprint makes Majors direction a control, not an evolution target.
2. **The raw probabilities are badly miscalibrated.** Agents put 11–34% on a >2% move within 4 hours, against an
   actual 6.7%. Clef-flash is the worst offender; DeepSeek with a volatility directive is the only agent near the
   true rate (5.8%).
3. **Shrinking toward the baseline removes almost all of the damage, and the signal with it.** Fitted on the first
   half, most weights land at 0.05–0.15. Only Clef with the reversion directive keeps a meaningful weight (0.45), and
   it does not hold up in the second half (+0.007, within noise).
4. **Model diversity beats prompt diversity.** Per-card excess losses correlate 0.78 between two agents on the same
   model and 0.40 across models. Six directives on one model behave like one forecaster with six biases.
5. **"Persistence" here is persistent bias, not skill.** Agent rankings in the two halves correlate at 0.96, because
   miscalibration is stable. Persistence only means something once agents are calibrated.
6. **Bigger is better within a family; reasoning helps calibration.** Clef beats Clef-flash on every directive.
   DeepSeek with low reasoning beats DeepSeek without reasoning, by a wide margin on the 4-hour question.

## What this changes
- **Agents should adjust a quantitative prior, not produce raw probabilities.** On numeric cards a simple model is
  strictly better than an LLM turning numbers into odds. The card should carry the prior, and the agent should move
  it only when it sees a reason. Scoring stays against the same prior.
- **A learning layer is mandatory.** Shrinkage and a settlement-aware Hedge pool are what make a swarm safe to
  aggregate: the Hedge pool with the reference included never does materially worse than the reference.
- **Diversity has to come from models and data views, not directives.** Pre-season genomes should vary which
  slice of information an agent sees.
- **Test where LLMs have an edge: text and messy, less efficient markets.** Next: Events (resolved Polymarket
  questions, scored against the market price at forecast time), then Trenches.

## Operational notes
- Workers AI rate-limits DeepSeek at 16 parallel requests (HTTP 429 after six retries); the client now caps it at 4.
- Unbounded DeepSeek reasoning used the whole token budget without answering; reasoning is capped.
- Runs are resumable and stop on rejected credentials instead of recording thousands of failures.
